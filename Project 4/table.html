HTML Tables

Tables are used to display data in rows and columns.

1. Basic Table

The main table tags are:

  • <table> - creates the table
  • <tr> - creates a row
  • <th> - creates a table header cell
  • <td> - creates a data cell
Name Age City
Navdeep 25 Delhi
Riya 22 Jaipur

Example:

<table border="1">
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Navdeep</td>
    <td>25</td>
  </tr>
</table>

2. Table Header, Body, and Footer

Large tables can be split into sections.

Product Price
Phone $500
Laptop $900
Total $1400

Example:

<thead>
  <tr><th>Product</th><th>Price</th></tr>
</thead>
<tbody>
  <tr><td>Phone</td><td>$500</td></tr>
</tbody>

3. Colspan

colspan makes one cell stretch across multiple columns.

Name Contact
Navdeep 123456 navdeep@email.com

Example:

<th colspan="2">Contact</th>

4. Rowspan

rowspan makes one cell stretch across multiple rows.

Name Role
Navdeep Student
Developer

Example:

<td rowspan="2">Navdeep</td>

5. Caption

The <caption> tag adds a title to a table.

Student Information
Name Course
Riya HTML

Example:

<table border="1">
  <caption>Student Information</caption>
</table>

6. Cellpadding and Cellspacing

These attributes help control spacing inside and between cells.

Month Sales
January $1500

Example:

<table border="2" cellpadding="8" cellspacing="2">
    ...
</table>

8. Summary

  • <table> defines the table
  • <tr> defines a row
  • <th> defines a heading cell
  • <td> defines a normal cell
  • <thead> defines header content
  • <tbody> defines body content
  • <tfoot> defines footer content
  • colspan merges columns
  • rowspan merges rows
  • caption adds a title to the table
