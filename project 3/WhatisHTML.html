What Is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on web pages.

How HTML works

HTML elements describe the purpose of content, such as a heading, paragraph, link, image, or list. A web browser reads these elements and displays the page accordingly.

Common HTML elements

  • <h1> creates a top-level heading.
  • <p> marks a paragraph.
  • <a> creates a link to another page or resource.
  • <img> embeds an image.
  • <ul> and <ol> create unordered and ordered lists.

HTML and programming

HTML is a markup language, not a programming language. It labels and organizes content; CSS is commonly used to style it, and JavaScript can add interactive behavior.
