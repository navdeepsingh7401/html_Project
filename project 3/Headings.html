HTML Headings

HTML provides six heading levels:

Main Heading

Subheading

Smaller Heading

Heading 4

Heading 5
Heading 6

h1 is the highest-level heading, while h6 is the lowest-level heading.

For example:

My Website

About Me

I am a web developer.

My Skills

HTML

CSS

Important: Don't choose headings simply because you want bigger or smaller text. Use them to represent the structure of your content. CSS should be used when you want to change the visual size.
