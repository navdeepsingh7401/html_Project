HTML Paragraphs and Text Formatting

1. Paragraphs

The <p> tag is used to create a paragraph in HTML.

This is my first paragraph.

This is my second paragraph.

Paragraphs are usually displayed with space between them, which helps make the content easier to read.

Example:

<h1>About HTML</h1>
<p>HTML is used to structure web pages.</p>
<p>It works together with CSS and JavaScript.</p>

2. Text Formatting

HTML gives us several tags to format text and give it meaning.

<b> — Bold

This is bold text.

Note: <b> makes text look bold, but it does not add special semantic importance.

<strong> — Strong importance

This is very important.

It normally appears bold, but it also tells the browser and assistive technologies that the text is important.

<i> — Italic

This is italic text.

It represents text in an alternate voice or mood, or other conventional italicized text.

<em> — Emphasis

This is emphasized text.

It normally appears italic, but it also gives the text emphasis semantically.

For example: I really like HTML.

<u> — Underlined text

This is underlined text.

Important: do not use for links. Links are normally represented with the tag.

<mark> — Highlighted text

This is highlighted text.

It represents text that is relevant to the current context and is highlighted for attention.

Example: Search result: HTML tutorial

Quick comparison

Tag Appearance Main idea
<b> Bold Draw attention
<strong> Bold Strong importance
<i> Italic Alternate voice or mood
<em> Italic Emphasis
<u> Underlined Annotation
<mark> Highlighted Relevant or highlighted text

3. Comments

Comments are notes inside your HTML code that are not displayed on the webpage.

Syntax:

<!-- This is a comment -->

Example:

<h1>My Website</h1>

<!-- This paragraph introduces the website -->
<p>Welcome to my website!</p>

Comments are useful for explaining code and for temporarily disabling parts of HTML.

<!--
<p>This won't appear on the page.</p>
