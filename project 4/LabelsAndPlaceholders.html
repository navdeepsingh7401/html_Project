Labels and Placeholders

What is a label?

The <label> element helps describe the purpose of an input field. It improves accessibility and makes forms easier to use.

<label for="username">Username:</label>
<input type="text" id="username" name="username" placeholder="Enter your username">

What is a placeholder?

The placeholder attribute displays hint text inside the input before the user types anything.

<input type="email" placeholder="name@example.com">

Why use them?

  • Labels explain what the field is for.
  • Placeholders show a short example of expected input.
  • They improve user experience and accessibility.
