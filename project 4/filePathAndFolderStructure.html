File Paths and Folder Structure

What is a file path?

A file path tells the browser or system where to find a file. This is important for linking stylesheets, images, and other pages.

Relative Path

A relative path is based on the current file location.

img src="images/photo.jpg"
link rel="stylesheet" href="css/style.css"

Absolute Path

An absolute path gives the full location of a file.

<img src="/Users/navdeep/project/images/photo.jpg" alt="Photo">

Folder Structure Example

my-website/
├── index.html
├── about.html
├── images/
│   └── logo.png
├── css/
│   └── style.css
└── js/
    └── script.js

Examples

  • index.html is the homepage
  • images/logo.png is a path to an image file
  • css/style.css is a path to a stylesheet

Using paths in HTML

<img src="images/logo.png" alt="Website logo" width="150">

Remember: always use the correct relative path based on the current folder.
