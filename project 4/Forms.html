HTML Forms

HTML forms are used to collect user input, such as text, email, password, checkboxes, and more.

1. Basic Form Structure

The main form tags are:

  • <form> — creates the form
  • <input> — creates different input fields
  • <label> — labels the input
  • <textarea> — allows multi-line text input
  • <select> — creates a dropdown list
  • <button> — submits or triggers an action






Example:

<form>
  <label for="name">Name:</label>
  <input type="text" id="name" name="name">
  <input type="submit" value="Submit">
</form>

2. Text Input

The text input is used for a single line of text.

Example:

<input type="text" name="firstname">

3. Email Input

The email input is used to accept email addresses.

Example:

<input type="email" name="useremail">

4. Password Input

The password input hides the typed text.

Example:

<input type="password" name="pass">

5. Radio Buttons

Radio buttons let the user choose only one option.

Choose your favorite language:



Example:

<input type="radio" name="language" value="HTML">

6. Checkboxes

Checkboxes allow multiple selections.

Select your hobbies:



Example:

<input type="checkbox" name="hobby" value="Reading">

7. Textarea

The textarea element allows multi-line text input.


Example:

<textarea rows="4" cols="30"></textarea>

8. Select Dropdown

The select element creates a dropdown list.

Example:

<select>
  <option value="india">India</option>
  <option value="usa">USA</option>
</select>

9. Submit and Reset Buttons

Buttons are used to submit or reset the form.

Example:

<input type="submit" value="Submit Form">
<input type="reset" value="Reset">

10. Common Form Attributes

  • action — where the form data is sent
  • method — how the form is sent, usually GET or POST
  • name — identifies the field
  • placeholder — displays example text inside the input
  • required — makes a field mandatory

11. GET vs POST

GET sends form data in the URL. It is suitable for simple searches and requests.

POST sends form data in the request body. It is better for sensitive or larger data, like login and sign-up forms.

Example of GET

<form action="#" method="get">
  <input type="text" name="q">
  <input type="submit" value="Search">
</form>

Example of POST



<form action="#" method="post">
  <input type="text" name="username" placeholder="Enter username" required>
  <input type="submit" value="Register">
</form>
