HTML Input Types

The <input> element is one of the most important tools in HTML forms. The type attribute controls what kind of data the user can enter.

1. Text

Used for single-line text input.

<input type="text" name="name" placeholder="Enter your name">

2. Password

Used for passwords. The entered text is hidden.

<input type="password" name="password" placeholder="Enter password">

3. Email

Used for email addresses.

<input type="email" name="email" placeholder="example@email.com">

4. Number

Used for numeric input.

<input type="number" name="age" min="1" max="100">

5. Search

Used for search boxes.

<input type="search" name="search" placeholder="Search...">

6. Tel

Used for phone numbers.

<input type="tel" name="phone" placeholder="123-456-7890">

7. URL

Used for website URLs.

<input type="url" name="website" placeholder="https://example.com">

8. Date

Used for date selection.

<input type="date" name="dob">

9. Time

Used for time selection.

<input type="time" name="meeting-time">

10. Datetime-local

Used for date and time without timezone.

<input type="datetime-local" name="event-time">

11. Month

Used to select a month.

<input type="month" name="birthday-month">

12. Week

Used to select a week.

<input type="week" name="week-number">

13. Color

Used to select a color.

<input type="color" name="favorite-color" value="#ff0000">

14. Checkbox

Used to allow multiple selections.

Subscribe to newsletter 
<input type="checkbox" name="subscribe" checked> Subscribe to newsletter

15. Radio

Used when only one option can be selected.

Male Female 
<input type="radio" name="gender" value="male"> Male
<input type="radio" name="gender" value="female"> Female

16. File

Used to upload files.

<input type="file" name="resume">

17. Range

Used for selecting a value from a range.

<input type="range" name="volume" min="0" max="100" value="50">

18. Hidden

Used to store data that is not visible to the user.

<input type="hidden" name="user_id" value="101">

19. Submit

Used to submit the form.

<input type="submit" value="Submit">

20. Reset

Used to reset the form back to default values.

<input type="reset" value="Reset">

21. Button

Used to trigger JavaScript or a custom action.

<input type="button" value="Click Me">

22. Image

Used to submit a form with an image instead of a button.

<input type="image" src="image.png" alt="Submit button">

23. Full Example













<form>
  <input type="text" name="fullName">
  <input type="email" name="emailAddress">
  <input type="date" name="birthDate">
  <input type="color" name="favoriteColor">
  <input type="number" name="ageRange" min="1" max="100">
  <input type="submit" value="Submit Form">
</form>
