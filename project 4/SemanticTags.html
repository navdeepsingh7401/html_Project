Semantic HTML Tags

Semantic tags help explain the meaning of different parts of a webpage.

Common Semantic Tags

  • <header> - page or section header
  • <nav> - navigation links
  • <main> - main content
  • <section> - a group of related content
  • <article> - independent content
  • <aside> - related but secondary content
  • <footer> - page footer
